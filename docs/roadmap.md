# Roadmap

## 1. Source intake

Review the projects and sites provided by the maintainer. Add candidates and evidence, deduplicate the first intake, and identify categories with weak coverage. This phase is complete when every supplied source has been inspected and the resulting candidate records can be traced back to it.

## 2. First curated snapshot

Review candidates against the editorial method. Publish the core and situational selections with check dates, scope notes, and CSVs. Add catalog validation for field values, IDs, evidence references, and core eligibility. Check links separately so offline validation stays repeatable.

## 3. Offline catalog exports

Start with a searchable UTF-8 text index and a self-contained HTML index organized by category and title. Include each resource's description, edition, format, and source URL. Add a plain-text or EPUB reading bundle for resources that permit transformation and redistribution. Keep display simple enough for e-ink. Use short headings, navigable sections, and searchable text without relying on external assets.

## 4. Source conversion and integration

Pilot extraction with publisher HTML and text-based PDF. Handle scanned PDF with OCR only when output can be reviewed. Support selected ZIM articles by retaining archive and entry provenance. Preserve diagrams and tables when they carry essential meaning, or link readers to the corresponding original page. Check text search and navigation offline on a representative e-ink device and a browser before publishing bundles.

Document a versioned catalog import for PrepperCache after the first stable snapshot. Keep conversion output separate from the catalog data.
