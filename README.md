# DisasterReference

DisasterReference is a public catalog of documents worth keeping offline for emergencies. It compares independent preparedness projects, public agencies, and other credible sources to find the references most useful before, during, and after a disaster.

The first release will aim for a short, broadly applicable list, with additional references for specific hazards, regions, and equipment. Each recommendation will point back to the publisher and show the evidence behind its inclusion. The catalog will use categories familiar to [PrepperCache](https://github.com/A2ThreeD/PrepperCache) so a future integration can reuse the metadata.

## Start here

- [Resources CSV](catalog/resources.csv) records titles, descriptions, topics, links, formats, editions, and review status.
- [Evidence CSV](catalog/evidence.csv) links each resource to the sources that recommend or discuss it.
- [Catalog schema](docs/catalog-schema.md) explains categories and how to add records.
- [Editorial method](docs/editorial-method.md) explains how candidates are compared and how the core list is selected.
- [Roadmap](docs/roadmap.md) covers the initial research and offline exports.
- [Contributor and agent instructions](AGENTS.md) apply to work in this repository.

The CSVs currently contain headers only. Source intake starts with the projects and sites supplied by the maintainer. The repository catalogs third-party references by link. Rights for source documents and derived exports must be tracked per resource.

## Contribute a source

Open an issue with the original URL, publisher, the resource or topic it covers, and where the recommendation appears. Include the edition, intended audience, region, and any known access or reuse terms when available. A link to a whole preparedness library is also welcome. Identify specific documents or sections whenever you can.
